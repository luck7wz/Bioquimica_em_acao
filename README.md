Bioquímica em Ação 🧪🧬

O Bioquímica em Ação é uma plataforma educacional desenvolvida para auxiliar estudantes nos estudos de Química e Biologia através de um chatbot inteligente e ferramentas interativas de aprendizagem.

O projeto foi criado com foco em acessibilidade, praticidade e aprendizado dinâmico, oferecendo uma experiência moderna para estudantes do ensino médio, vestibulares e ENEM.

🚀 Funcionalidades
🤖 Chatbot educativo com Inteligência Artificial
📚 Resumos inteligentes
📝 Gerador de questões
🧠 Flashcards interativos
🎯 Simulados estilo ENEM
📖 Artigos educativos
📱 Layout responsivo
🌐 Interface moderna e intuitiva
💻 Tecnologias Utilizadas
HTML5
CSS3
JavaScript
Font Awesome
Google Fonts

🎯 Objetivo do Projeto

O objetivo principal do projeto é facilitar o aprendizado de conteúdos relacionados à biologia e química através da tecnologia, tornando os estudos mais acessíveis, rápidos e interativos.
